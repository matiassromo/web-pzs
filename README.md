# 🌊 Piscina Zero Stress - Página Web Oficial

Este repositorio contiene el código fuente de la página web **Piscina Zero Stress**, diseñada para ofrecer información clara, atractiva y funcional sobre los servicios de la piscina, con el objetivo de brindar a los clientes una experiencia digital amigable.

## ✨ Características principales

- **Diseño Responsivo**: Adaptado para escritorio, tablet y dispositivos móviles.
- **Secciones informativas**: Servicios, galería, horarios, contacto y mapa de ubicación.
- **Interactividad**: Animaciones, modal de servicios y carrusel dinámico.
- **Integración con Google Maps**: Ubicación exacta de la piscina.
- **Optimización SEO**: Títulos, metaetiquetas y favicon configurados.

## 🛠️ Tecnologías utilizadas

- **Frontend**: HTML5, CSS3, JavaScript.
- **Frameworks/Librerías**: Bootstrap 5, Animate.css.
- **Hosting**: Netlify.
- **Dominio**: Adquirido y gestionado directamente desde Netlify.

## 📂 Estructura

```text
/
├── index.html       # Página principal
├── estilos.css      # Estilos personalizados
├── scripts.js       # Funciones dinámicas
├── /images          # Logos, fotos y recursos visuales
├── /favicon         # Iconos de la web
└── README.md        # Documentación del proyecto
```

## 🚀 Despliegue

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/matiassromo/web-pzs.git
   ```
2. Abrir `index.html` en el navegador.  
3. O visitar la página en producción: 👉 [Ver sitio](https://piscinazerostress.com)
